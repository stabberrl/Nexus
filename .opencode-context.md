# Nexus AI - Session Context

## Project Overview

**Nexus AI** is a personal AI assistant with local Ollama-powered LLM. It has a multi-agent architecture with a Python FastAPI backend + Tauri desktop app (React/TypeScript). All AI runs locally (no cloud).

## Architecture Decisions

### Multi-Agent System
- **Coordinator** (main LLM): Generates final responses from task results
- **SystemAgent**: PC control (PowerShell, processes, files, screenshots, key input)
- **WebAgent**: Internet search + page scraping via Playwright (DuckDuckGo)
- **CodeAgent**: Python code execution in sandbox (whitelist modules, blacklist patterns)
- **DocumentsAgent**: Document creation (Word, Excel, PowerPoint) — lazy-loaded libraries

### Backend API (port 8000)
- `GET /` - Health check
- `GET /api/system` - System stats (CPU, RAM, disk, uptime)
- `GET /api/models` - List Ollama models
- `POST /api/chat` - Chat via REST
- `GET /api/memory` + `POST /api/memory` - Factual memory
- `GET /api/memory/history` - Conversation history
- `POST /api/code/run` - Execute Python
- `POST /api/plan` - Task planning
- `WebSocket /ws/chat` - Chat with streaming tokens + multi-agent task tracking

### Frontend (port 1420)
- Two views: Chat and "Oficina Virtual" (canvas-based agent visualization)
- WebSocket for streaming, REST fallback
- Dark theme with neon accent colors
- Suggestions chips for common tasks

### Memory System
- **SQLite**: Conversations, facts (key-value), tasks, agent state
- **ChromaDB**: Semantic memory using nomic-embed-text via Ollama
- Lazy loading: ChromaDB only loads when semantic search is used

### Startup Flow
1. VBS/BAT/PS1 launcher starts `pythonw -m backend.api.main`
2. Waits for health check on port 8000
3. Opens Tauri app (if compiled) or browser at localhost:1420
4. Tauri `lib.rs` auto-finds project root, spawns backend Python process, kills it on exit

### Security
- `windows_subsystem = "windows"` in release (no terminal window)
- Python sandbox: whitelisted modules only, blocked patterns (os, subprocess, eval, exec)
- CSP is null (wide open - may need tightening)
- CORS allow_origins=["*"] (dev setting)
